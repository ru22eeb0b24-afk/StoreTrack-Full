# StoreTrack 

A simple Inventory and Order Management System built as part of an assessment project.

#Tech Stack
- React (Frontend)
- FastAPI (Backend)
- PostgreSQL
- Docker

# Features
- Manage Products
- Manage Customers
- Manage Orders
- Inventory Tracking
- Low Stock Alerts
