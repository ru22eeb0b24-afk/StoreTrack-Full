# StoreTrack 

Inventory and Order Management System built using FastAPI and React.

#Features
- Product Management
- Customer Management
- Order Management
- Stock Validation
- Unique Product SKU Validation
- Unique Customer Email Validation

#Tech Stack
- Frontend: React (Vite)
- Backend: FastAPI
- Containerization: Docker
- Deployment: Vercel + Render
